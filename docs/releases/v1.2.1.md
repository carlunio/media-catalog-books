# MC Books 1.2.1

Esta versión permite detectar e instalar nuevas releases directamente desde
la interfaz de MC Books.

## Actualización desde la interfaz

- El menú lateral muestra el estado de actualización junto a la versión.
- MC Books consulta la última release estable publicada en GitHub.
- La comprobación se actualiza automáticamente cada 15 minutos.
- Cuando existe una versión posterior, aparece el botón «Actualizar a X.Y.Z».
- Al pulsarlo, MC Books detiene frontend y backend, actualiza la instalación y
  vuelve a abrir la aplicación en la misma dirección.

## Seguridad y recuperación

- La actualización utiliza el controlador existente de `appctl`.
- Las solicitudes quedan vinculadas a la instancia activa.
- Los cambios locales nunca se sobrescriben.
- Se mantienen la copia de seguridad de DuckDB y la reversión automática si la
  versión nueva no arranca correctamente.
- El flujo funciona tanto en Linux como en Windows.

## Validación

- 123 pruebas automatizadas superadas.
- Ruff y Black superados.
- Prueba de humo de backend, frontend y base temporal superada.
- Paquetes fuente y wheel construidos correctamente.
- Interfaz validada en modo headless.
