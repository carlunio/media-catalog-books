# MC Books 1.2.0

Esta versión mejora la ejecución del flujo de catalogación, la revisión manual,
la interfaz de usuario y la configuración de modelos locales y de OpenAI.

## Orquestación y estabilidad

- Ejecución de lotes en segundo plano.
- Panel de progreso por etapa y por libro.
- Botón de detención controlada.
- Restauración del libro a su última etapa válida al detener una ejecución.
- Los reintentos iniciados desde Revisión aparecen también en Orquestación.
- Protección frente a ejecuciones simultáneas sobre la misma base de datos.
- Límite de 60 segundos por imagen OCR, configurable mediante
  `OCR_TIMEOUT_SECONDS`.
- Los timeouts de OCR envían el libro a Revisión y el lote continúa con el ID
  siguiente.

## Modelos y OCR

- GPT-6 Luna pasa a ser el modelo recomendado de OpenAI para catalogación.
- GPT-6.1 Sol continúa disponible como alternativa manual.
- Cada modelo dispone de un perfil propio de API, razonamiento, temperatura y
  salida estructurada.
- OpenAI puede utilizarse como alternativa remota para OCR en equipos lentos.
- El OCR remoto usa Responses API, razonamiento bajo y detalle original.
- La extracción posterior del ISBN utiliza el mismo proveedor seleccionado.
- El OCR local continúa siendo la opción predeterminada.

## Revisión y formulario

- Las revisiones permiten repetir fases con las mismas opciones disponibles en
  Orquestación.
- Nueva acción para guardar un ISBN válido y salir de revisión en un solo paso.
- Las fichas editables se crean automáticamente al terminar la catalogación.
- El formulario recupera todo el ancho disponible al contraer el menú lateral.
- Los nombres de los campos con formatos especiales permiten abrir su ayuda sin
  añadir iconos que resten espacio.
- Las columnas del Excel de revisión externa siguen un orden lógico por grupos.

## Interfaz y documentación

- El nombre comercial de la aplicación pasa a ser MC Books.
- Nueva jerarquía visual para páginas, formularios, estados y acciones.
- El estado del módulo aparece antes de las órdenes de Orquestación.
- Se amplía la documentación de configuración, campos, ciclo de las fichas,
  instantáneas y revisión externa.

## Validación

- 114 pruebas automatizadas superadas.
- Ruff y Black superados.
