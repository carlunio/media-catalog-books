# Media Catalog Books 1.1.0

Esta versión amplía la preparación de imágenes, mejora la obtención de
metadatos y portadas y añade un flujo completo para revisar fichas fuera de la
aplicación mediante Excel.

## Principales novedades

- Nuevo proceso seguro para preparar imágenes antes de la extracción:
  - análisis previo sin modificar archivos;
  - listado de renombrados, conversiones y borrados;
  - confirmación explícita antes de aplicar los cambios;
  - conversión de HEIC/HEIF a JPEG, respetando la orientación EXIF;
  - borrado opcional de los originales;
  - detección de nombres imposibles, colisiones, módulos incoherentes e
    imágenes duplicadas o ausentes.
- Nuevo sistema de revisión externa mediante Excel:
  - exportación desde la sección **Datos**, filtrando por módulo y estado;
  - archivos `.xlsx` Unicode con los campos editables del formulario;
  - cabeceras, colores y listas desplegables equivalentes a los de la
    aplicación;
  - validación de formatos y conflictos antes de importar;
  - vista previa y confirmación de todos los cambios;
  - actualización atómica de las fichas;
  - regeneración automática de la descripción;
  - opción de conservar el estado actual o consolidar las fichas importadas.

## Metadatos y API bibliográficas

- Google Books admite una clave de API configurada para el proyecto.
- Se añade una búsqueda alternativa por título cuando la búsqueda inicial de
  Google no devuelve resultados. La coincidencia se valida siempre mediante el
  ISBN exacto.
- Las fichas de Google registran si se obtuvieron directamente por ISBN o
  mediante la búsqueda alternativa.
- Open Library separa los datos de la edición concreta de la información
  general de la obra.
- Los datos de publicación proceden de la edición, mientras que la sinopsis y
  las materias de la obra pueden utilizarse para completar categoría y género.
- Los resultados muestran por separado el estado de Google Books, Open Library
  e ISBNdb.
- Google reintenta automáticamente las respuestas transitorias `429` y `5xx`.
- Los errores HTTP se guardan sin exponer las credenciales.
- Los intervalos predeterminados de Google Books y Open Library se reducen de
  60 a 1 segundo.

## Descarga de portadas

- La descarga de portadas se ejecuta como una rama opcional durante la fase de
  metadatos.
- Se revisan todas las fichas del módulo que no tengan un archivo de portada,
  aunque no haya fichas pendientes de consultar en las API.
- Si una portada se elimina manualmente, la aplicación intenta descargarla
  otra vez.
- Las portadas `large` y `medium` de Open Library y Google tienen prioridad
  frente a miniaturas y a imágenes de ISBNdb.
- Las portadas también pueden descargarse para fichas consolidadas sin
  desbloquearlas ni modificar su estado.
- Los errores al descargar una portada no detienen el resto del procesamiento.

## Flujo de trabajo y estabilidad

- La sobrescritura solo repite la etapa seleccionada y las etapas posteriores
  activas.
- Se excluyen de la sobrescritura los libros terminados, en ejecución,
  pendientes de revisión o con la ficha consolidada.
- El redimensionado a 1800 px para OCR queda desactivado de forma
  predeterminada.
- Los lotes dejan de tener un tiempo de espera HTTP global.
- Cada consulta bibliográfica y cada operación de OCR o catalogación dispone
  de su propio tiempo de espera.
- Un error o bloqueo en un elemento no impide procesar el resto del lote.
- Se corrigen las pruebas de integración continua en Linux y Windows.

## Instalación y dependencias

`pyproject.toml` pasa a ser la única declaración de dependencias. Se eliminan
`requirements.lock`, `pip-tools` y sus comandos asociados.

El entorno se reconstruye automáticamente cuando cambia `pyproject.toml`.
También puede forzarse mediante:

```bash
make install
```

o:

```bash
python scripts/appctl.py setup --force
```

Las instalaciones que todavía utilicen una versión anterior del controlador
pueden necesitar esta actualización manual una sola vez.
